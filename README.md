## 🧰 Tecnologias

| Tecnologia | Descrição |
| ---------- | --------- |
| [React 19](https://react.dev) | Biblioteca de UI, com o React Compiler habilitado |
| [Vite](https://vite.dev) | Build tool e dev server |
| [TypeScript](https://www.typescriptlang.org) | Tipagem estática |
| [Tailwind CSS v4](https://tailwindcss.com) | Estilização utilitária |
| [shadcn/ui](https://ui.shadcn.com) + [Base UI](https://base-ui.com) | Componentes de UI |
| [Storybook 10](https://storybook.js.org) | Documentação e desenvolvimento isolado de componentes |
| [Biome](https://biomejs.dev) | Lint e formatação |
| [Husky](https://typicode.github.io/husky) + [lint-staged](https://github.com/lint-staged/lint-staged) + [commitlint](https://commitlint.js.org) | Git hooks e padronização de commits (gitmoji) |

## 🚀 Como rodar

Instale as dependências:

```bash
pnpm install
```

Rode a aplicação:

```bash
pnpm dev
```

Rode o Storybook:

```bash
pnpm storybook
```

> O Storybook abre em [http://localhost:6006](http://localhost:6006).
